{
  complaint: Object,        // Complaint data
  isOpen: boolean,         // Visibility state
  onClose: function,       // Close handler
  onEdit: function,        // Edit handler (new)
  onReassign: function,    // Reassign handler (new)  
  onDelete: function       // Delete handler (new)
}

ReassignModal Props:
{
  isOpen: boolean,         // Visibility state
  onClose: function,       // Close handler
  complaint: Object,       // Complaint to reassign
  officers: Array,         // Available officers
  onReassign: function     // Reassign handler
}

Action Handlers:
• editComplaint(complaint) → Shows edit interface
• reassignComplaint(complaint) → Opens reassign modal
• deleteComplaint(complaint) → Confirms and deletes
• performReassign(complaint, officerId) → API call
