 *  │   └── Bell Icon ────────────────┤
 *  │                                  │
 *  ├── Main Content                  │
 *  │   └── [Dashboard Content]       │

 *      │   ├── Backdrop (Blur)

 *      │       ├── Header
 *      │       ├── Body
 *      │       │   ├── Avatar

 *              └── Footer              │

 * STATE FLOW:
 * ===========
 * 
 *  User Action          State Change         UI Update
 *  ───────────          ────────────         ─────────
 *  
 *  Click Profile   →   showProfile: true   →  Profile Popup Opens
 *  Button              showNotifications:      + Backdrop appears
 *                      false                   + Background blurs
 *                                              + Content blocks clicks
 *  
 *  Click Outside   →   showProfile: false  →  Profile Popup Closes
 *  Backdrop                                    + Backdrop fades out
 *                                              + Background unblurs
 *                                              + Content clickable again
 *  
 *  Click Bell      →   showNotifications:  →  Notification Popup Opens
 *  Icon                true                    + Profile closes first
 *                      showProfile: false      + Backdrop appears
 *                                              + Background blurs
 * 
 * 
 * Z-INDEX LAYERING:
 * =================
 * 
 *  Layer 9999: ┌──────────────────────┐
 *              │   Popup Panels       │ ← Front (Clickable)
 *              │  - ProfilePopup      │
 *              │  - NotificationPopup │
 *              └──────────────────────┘
 *  
 *  Layer 9998: ┌──────────────────────┐
 *              │   Blurred Backdrop   │ ← Middle (Blocks clicks)
 *              │  + backdrop-filter   │
 *              │  + rgba(0,0,0,0.4)   │
 *              └──────────────────────┘
 *  
 *  Layer 1-100:┌──────────────────────┐
 *              │  Regular Content     │ ← Back (Blurred when popup open)
 *              │  - Navbar            │
 *              │  - Dashboard         │
 *              │  - Cards/Tables      │
 *              └──────────────────────┘
 * 
 * 
 * CSS ANIMATIONS:
 * ===============
 * 
 *  Backdrop:
 *  ┌─────────────────────────────────┐
 *  │ fadeIn (0.3s)                   │
 *  │ opacity: 0 ──→ opacity: 1       │
 *  └─────────────────────────────────┘
 *  
 *  Popup Panel:
 *  ┌─────────────────────────────────┐
 *  │ slideInScale (0.3s)             │
 *  │ transform: translateY(-20px)    │
 *  │           scale(0.95)           │
 *  │         ──→                     │
 *  │ transform: translateY(0)        │
 *  │           scale(1)              │
 *  └─────────────────────────────────┘
 *  
 *  Notification Items:
 *  ┌─────────────────────────────────┐
 *  │ slideInLeft (0.3s, staggered)   │
 *  │ transform: translateX(-20px)    │
 *  │         ──→                     │
 *  │ transform: translateX(0)        │
 *  └─────────────────────────────────┘
 * 
 * 
 * EVENT HANDLING:
 * ===============
 * 
 *  ProfileButton.onClick()
 *  │
 *  ├─→ setState({ showProfile: true, showNotifications: false })
 *  │
 *  └─→ Renders:
 *      ├─→ <div className="popup-backdrop" onClick={onClose}>
 *      └─→ <div className="popup-panel">
 * 
 *  backdrop.onClick()
 *  │
 *  └─→ onClose()
 *      └─→ setState({ showProfile: false })
 *          └─→ Component unmounts (isOpen = false)
